## The contact directory

The purchased list never enters the repository: no seed, no fixture, no migration and no screenshot carries a real row, and it reaches the database only through the hand run `pnpm directory:import`, which refuses a hosted database until `IMPORT_POLICY.status` in `src/features/directory/import-policy.ts` is `'cleared'` in a commit that also carries the lawyer's dated `licenceNote` and the countries they named (the launch gate, AC-17). The six `directory_*` tables carry no select policy for `authenticated` but the ops one, so the database is the only thing that ever masks or reveals a value: `directory_search` and `directory_unlocked_contacts` are the only read paths, `private.mask_email` and `private.mask_phone` the only masks, and `directory_reveal` the only debit, checking the balance, inserting the unlock and returning the row in one transaction under `pg_advisory_xact_lock`. Credits are an append only ledger whose balance is `sum(delta)`, never a stored column. An expert is a second buyer shape on `orders` and `invoices` (`buyer_expert_id`, `orders_check_buyer` holding exactly one shape per row), so a credit pack is an ordinary order on the spec 0011 rail: `settle_order` grants `the_order.credits` in the same transaction as `paid`, guarded by the partial unique index on `(order_id) where reason = 'purchase'` so any number of settle retries grant once, and `orders.credits` is frozen at purchase so a resized pack never changes a pending invoice. The expert insert policy checks the package `kind` **and** the `credits` against `packages`, because `orders` has `UPDATE` revoked and that policy is the only guard against an expert minting their own credits. An expert order never enters a delivery state: `private.check_order_transition` raises and `classifyScheduleError` maps the fragment to `not_deliverable`. Every buyer facing alert names the buyer through `buyerLabel` in `src/features/checkout/buyer.ts`, never a direct `organizations` join, because an expert order's `organization_id` is null. Strings live in the `directory` namespace in both catalogs; the three events carry ids and codes only. The per environment checklist (the lawyer's commit, the staging import as the last step, one real purchase and reveal, the Slack alert, the two invoices and the CSV) lives in `docs/directory.md`.
